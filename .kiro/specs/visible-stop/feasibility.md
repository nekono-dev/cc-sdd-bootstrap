- 理由: 追加の文脈（`additionalContext`）だけで、止めた入力に応答の文章が作られ、リモートセッション・コマンドライン・Codex の画面で読めるかは、Claude Code・Codex の動作に依存する。現在の事象は、リモートセッションの記録（2026-11-26、Claude Code 2.1.329）で、入力を `decision: block` で止めると `num_turns=0` で応答が作られず、画面に出ないことを確認済み。次の前提を設計の前に実機で確かめる。

  - (c) 止める指示を受けたモデルが、手順書を読まず・作業せずに、理由を伝えて終える（auto モードを含む）。
