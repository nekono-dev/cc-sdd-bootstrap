## Implementation Notes
- 2.1: 利用者が書く JSON（設定ファイル・.claude/settings.json）は、途中の親が想定の型でない場合を検証で弾き、後段で `{}` に置き換えて黙って上書きしない。対応の形のキーに `__proto__`・`constructor`・`prototype` を通さない。
- 2.4: 末尾に改行の無いファイルに区画を足すと改行を 1 つ補うため、取り除いても末尾の改行は残る（中身の文字は変わらない）。復元を確かめるテスト（3.3・6.1）は末尾に改行のある元の内容を使う。
- 3.1: 記録（installed.json）に載る道筋は、配置先のディレクトリの下にあるものだけを消す対象にする（記録は壊れる・書き換えられうる）。カタログから外れた固有の部分は、書き換えられていれば残す。
- 3.2: 「補った項目」の知らせは計画ではなく cli が出す（計画は補った後の設定を受け取る）。記録の無い固有の部分でも、同梱の内容と同じなら記録に載せる（uninstall で消える。中身は同梱と同じなので失うものは無い）。
- 5.2: 対話は入力の終わり（EOF）で、既定値が正しくなければ「入力が終わりました」の Error を投げる。5.3 の runCli はこれを受けて失敗（終了コード 1）にする。
- 6.1: 入口は process.exit ではなく process.exitCode で終える（標準出力が管でつながると書きかけの出力が捨てられる）。Codex のサンドボックスでは子プロセスの起動が EPERM になることがあり、テストの失敗と取り違えない。
