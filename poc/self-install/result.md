- 実行日: 2026-11-23
- 環境: Node.js v22.16.0、Claude Code 2.1.329、Codex CLI 0.167.0、cc-sdd 3.1.0
- 実行: `node poc/self-install/run.mjs`
- 作業場所: `~/.cache/cc-sdd-bootstrap-scratch/self-install`

## 確かめること

- 起動前に導入し、両方の標準文書で運用の区画が 1 つだけ末尾にあること、Claude Code の起動時スキル一覧と Codex のスキル利用を確認する。
- `init` のみの別リポジトリで、最初の入力時の導入、追加文脈による手順書の成功した直接読み取り、導入状態の記録を両ツールで確認する。
- 存在しない版を指定した別リポジトリで、正常に完了した呼び出しの中で入力が止まり、失敗記録が残ることを確認する。起動失敗・時間切れ・通信障害は停止成功に数えない。
- Codex 用の認証写しは `CODEX_HOME` 内だけで使用し、各実行後に削除する。
